## Project Overview
A web-based Car Rental Management System that automates vehicle booking,
availability tracking, and fleet management for small rental businesses.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Dev Environment: XAMPP
- Version Control: Git & GitHub
- Design: Figma

## Project Structure
- `/frontend` — client-facing pages (HTML/CSS/JS)
- `/backend` — server-side logic and API endpoints (PHP)
- `/database` — SQL schema and database scripts
- `/docs` — proposal, requirement gathering, and design diagrams

## Setup Instructions
1. Clone this repository
2. Import `database/schema.sql` into MySQL via phpMyAdmin
3. Place project folder in `htdocs` (XAMPP)
4. Start Apache and MySQL via XAMPP Control Panel
5. Visit `localhost/Group-Project/frontend` in your browser
